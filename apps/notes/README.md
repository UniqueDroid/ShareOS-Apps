# ShareNotes

Farbige Notizzettel für ShareOS.

- **Schnell notieren:** oben schreiben, mit Klick daneben, Esc oder Strg+Enter ist die Notiz angelegt – mit Titel und einer von acht Farben.
- **Bearbeiten:** Klick auf eine Notiz öffnet sie; Titel, Text und Farbe ändern, Esc oder Klick daneben speichert. Leer geräumte Notizen verschwinden, Löschen fragt nach.
- **Suchen** in Titeln und Texten.
- **Auf der Box** (Berechtigung `files`): jede Notiz ist eine Datei `notes/note_<id>.json` im persönlichen Ordner – sie ist im Dateibrowser zu sehen und wird mit dem Ordner gesichert. Ohne Dateizugriff bleiben die Notizen im Browser (je Konto getrennt).
- Im ShareOS-Look (hell/dunkel, Akzentfarbe).
